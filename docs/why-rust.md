# Why Rust?

lfspla.net began life as a Python FastAPI application with a Svelte frontend.

Over time I realised that:

- I was rebuilding more and more work that already existed as part of [insim.rs](https://github.com/theangryangel/insim.rs)
- Typed Python feels to me like a worse version of Rust
- Writing Python for this project increasingly felt like writing Python at work. I
  didn't want that.
- Because I wanted to.
